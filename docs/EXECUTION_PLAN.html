3. المراحل التفصيلية

المرحلة 0 — التعلم والتأسيس
4-8 أسابيع

اكتساب المهارات الأساسية قبل البناء الفعلي.

  • HTML/CSS/JavaScript الأساسي
  • دورة React رسمية من react.dev
  • مشروع Next.js تجريبي صغير
  • أساسيات SQL + Prisma
  • تجربة Three.js: عرض مكعب 3D
  • إعداد بيئة العمل: VS Code, Node.js, Git, GitHub
المرحلة 1 — MVP (الإصدار التجريبي)
8-12 أسبوع

إصدار قابل للعرض على مستخدم تجريبي واحد.

  • إنشاء مشروع Next.js + النشر على Vercel
  • قاعدة بيانات + Prisma + NextAuth
  • إدارة Workspaces والمستخدمين
  • مكتبة قوالب (جداول + صور بدون 3D)
  • محرر 2D مبسط بالسحب والإفلات
  • محرر خصائص الوحدة (Component Options)
  • إدارة العملاء + فاتورة طباعة بسيطة
المرحلة 2 — العرض ثلاثي الأبعاد
8-12 أسبوع

الترقية من 2D إلى محرر 3D كامل.

  • دمج Three.js + React Three Fiber
  • تحويل القوالب لنماذج 3D برمجية (procedural)
  • السحب والإفلات + الدوران 45° + قلب الاتجاه
  • اللصق الذكي بين الوحدات (Snap)
  • كاميرا حرة + إضاءة وظلال
  • إضافة الجدران والأرضية
المرحلة 3 — مخطط القص والتقارير
6-8 أسابيع

تحويل التصميم لإنتاج فعلي في الورشة.

  • توليد قائمة قطع (Parts) لكل وحدة 3D
  • دمج خوارزمية Bin Packing
  • رسم مخطط القص بصرياً (SVG)
  • تقرير ورشة بصيغة PDF
  • قائمة المشتريات والإكسسوارات تلقائياً
المرحلة 4 — التدويل (3 لغات)
3-4 أسابيع

دعم العربي + الإنجليزي + الصيني بشكل احترافي.

  • إعداد next-intl
  • ترجمة كامل الواجهة
  • التعامل مع RTL/LTR
  • تنسيق الأرقام والعملات حسب اللغة
  • تنبيه: الصينية تحتاج مترجم محترف
المرحلة 5 — الإطلاق والتسويق
مستمر

الميزات المتقدمة، الاشتراكات، التسويق.

  • الاشتراكات والدفع (Stripe)
  • الخطط: مجاني، احترافي، مؤسسات
  • لوحة تحكم إدارية
  • دعوة أعضاء فريق للـ Workspace
  • رابط معاينة عام للعميل
  • موقع تعريفي + توثيق + تسويق
المرحلة 6 — ميزات AI المتقدمة
14 أسبوع

الميزات الذكية اللي تميّزنا عن كل المنافسين.

  • MCP Server داخلي: AI داخل المحرر يفهم الأوامر النصية
  • MCP Server عام: تكامل مع Claude/ChatGPT/Cursor
  • OAuth 2.1 + Streamable HTTP transport
  • Image-to-Design: رفع صورة → تصميم 3D قابل للتعديل
  • Vision AI (Claude Opus / GPT-4o) + Embeddings للقوالب
  • Beta مغلقة → إطلاق محدود → إطلاق عام

توزيع الطبقات

طبقة العميل (Frontend)

Next.js + React + Tailwind + shadcn/ui + Three.js — كل شيء يعمل في المتصفح.

طبقة الـ API (Backend)

Next.js API Routes في نفس المشروع — لا حاجة لخادم منفصل.

طبقة البيانات

PostgreSQL على Supabase + Prisma ORM للوصول الآمن.

طبقة التخزين

Cloudflare R2 للملفات الكبيرة (صور القوالب، نماذج 3D، PDFs).

8. نظام MCP — التحكم بالبرنامج عبر AI

MCP (Model Context Protocol) بروتوكول Anthropic المفتوح يخلي الـ AI (Claude/ChatGPT/Cursor) يتفاعل مع برنامجنا. تخيل المصمم يقول: "صمم مطبخ ركن 4×3 مودرن أبيض" والـ AI ينفذها في ثوان.

المعمارية: نوعان من التكامل

  subgraph IN["1- مساعد AI داخلي"]
    USER1[المصمم في المحرر] --> CHAT[شريط المساعد]
    CHAT --> AI1[Claude API]
    AI1 --> MCPI[MCP Tools داخلياً]
    MCPI --> EDITOR[محرر 3D]
  end

9. Image-to-Design — تحويل الصورة إلى تصميم

المستخدم يرفع صورة (مطبخ موجود، رسم يدوي، صورة Pinterest)، الذكاء الاصطناعي يحوّلها لتصميم 3D قابل للتعديل بدقة 95% (واقعياً نبدأ بـ 70-80% ونتحسن).

Pipeline التحويل

flowchart TB
  IMG[صورة المستخدم] --> META[إدخال أبعاد الغرفة
طول × عرض × ارتفاع]
  META --> VISION[Vision AI
Claude Opus 4.7 / GPT-4o]
  VISION --> JSON[JSON منظم
وحدات + مواقع + أبعاد + خامات]
  JSON --> EMBED[Embeddings
مطابقة مع القوالب]
  EMBED --> LIB[(مكتبة القوالب)]
  EMBED --> BUILD[توليد تصميم 3D]
  BUILD --> EDITOR[المحرر للتعديل]
  EDITOR --> SAVE[حفظ كمشروع]

إستراتيجية الإطلاق

1. Beta مغلقة

10-20 ورشة مختارة، مجاناً مقابل feedback، مدتها 3 أشهر.

2. جمع بيانات

كل تصميم متولد + التعديلات اليدوية = بيانات تدريب.

3. إطلاق محدود

الخطة Pro فقط، 50 تحويل/شهر، 3 أشهر.

4. إطلاق عام

بعد 6 أشهر بيتا، بدقة موثقة 85%+.

10. المخاطر والتحديات

الخطر الاحتمال الأثر كيف نتعامل معه
صعوبة محرر 3D عالي عالي استخدام React Three Fiber + قوالب procedural بسيطة

منافسة من شركات كبيرة متوسط متوسط التركيز على السوق العربي + الصيني أولاً
تكلفة AI API (Vision + Claude) عالي متوسط نظام Credits + حد أقصى للخطة المجانية + Caching
دقة Image-to-Design أقل من المتوقع عالي متوسط تسويق "تصميم مبدئي" + Beta طويلة + جمع بيانات تدريب
